AI FITNESS COACH - SETUP

1. Download the AI model (one time) from the official Google link:
   https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task
   If the school network blocks it, download it at home or on a phone hotspot.

2. Put pose_landmarker_lite.task inside the "models" folder.

3. Upload EVERYTHING in this folder to a GitHub repo (keep the wasm and models folders),
   then turn on GitHub Pages: Settings > Pages > Branch: main > Save.

4. Open the GitHub Pages link in Chrome, click "Start camera" and allow the camera.
